# **App Name**: Kisan AI

## Core Features:

- Dashboard: Dashboard: Central hub providing quick access to all features through navigation cards.
- Mandi Rates Display: Mandi Rates: Display the latest commodity prices from agricultural markets across India, using manual selection or geolocation.
- AI Voice Search: Mandi Rates Voice Search: Interpret spoken queries about commodity prices using the mandi-rate-nlu tool, then use mandi-rate-summary tool to provide a spoken summary via text-to-speech.
- Crop Image Analysis: Crop Doctor: Allow farmers to upload images of their crops or use their camera for real-time analysis.
- AI Crop Diagnosis: Crop Health Analysis: Analyze uploaded images with AI, factoring in local weather data to provide health status, solutions, and advisories using the crop-health-analysis tool.
- Scheme Information: Government Schemes: Display a curated list of relevant government schemes with descriptions and links to official websites.
- Language Settings: Settings: Allow users to switch the application's display language (English, Hindi, Marathi).

## Style Guidelines:

- Primary color: Forest green (#388E3C) to evoke nature and agriculture.
- Background color: Light sage (#E8F5E9), a very lightly desaturated tint of forest green.
- Accent color: Earthy yellow (#FDD835) to highlight important information.
- Body font: 'PT Sans', a humanist sans-serif font. Headline font: 'Space Grotesk', a contrasting sans-serif font with a contemporary, computerized look.
- Use Lucide React icons throughout the application for a consistent and modern look.
- Utilize a card-based layout (via ShadCN UI) for presenting information in a structured and easily digestible manner.
- Subtle transitions and animations on navigation and data loading to improve user experience.
